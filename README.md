# Port Scanner 🔍

## Introduction
This project is a simple Python tool that scans a range of ports on a target system and reports whether they are open or closed. It is designed to be lightweight and beginner-friendly.

## Project Purpose
The purpose of this project is to demonstrate the basics of socket programming and port scanning in Python. It helps learners understand how services run on different ports and how to identify open connections.

## Features
- Scans ports between 20 and 1024.
- Displays whether each port is open or closed.
- Uses Python’s built-in `socket` library.
- Clear and easy-to-read output.
