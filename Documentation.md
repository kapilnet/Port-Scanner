## Introduction
This project is a Python-based Port Scanner that scans a target host for open ports. It helps identify services running on a system and is a fundamental tool in cybersecurity for network analysis and vulnerability assessment.

## Project Purpose
The main objectives of this project are:

To understand how port scanning works in real-world scenarios.

To provide a simple tool for identifying open ports on a given IP address or domain.

To strengthen knowledge of Python networking libraries and socket programming.

## Features
Accepts target IP address or domain name.

Scans a range of ports (default: 1–1024).

Displays open ports with clear output.

Lightweight and easy to run from the terminal.

## Technologies Used
Programming Language: Python
Libraries: socket
IDE: VS Code

## Example
Enter target IP: 127.0.0.1
Scanning ports on 127.0.0.1...
Port 22: Open
Port 80: Open
Port 443: Open
Scan complete.
